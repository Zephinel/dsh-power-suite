## Highlights

- The current Session row now uses colored smoke: the colour keeps flowing instead of fading to grey, and reads stronger in light mode.
- The Running & recent card follows the native sidebar row geometry: time on the far right, disclosure triangle on the far left, matching right inset; a row shows one hover surface, and its icons take the title colour.
- Annotations on the card's status icons no longer report "no longer on the page"; icons are no longer pick targets, so a pick lands on a named button or the row.
- The Running & recent card scrolls with the wheel again on DSH 0.2.2.
- Bilingual UI copy uses one term per concept (Session, Workspace) and fixes plural, duplicate-count and missing-label composition bugs.
- New flat SVG app icon: a ruler, a browser-window card and a wrench rising out of a chat bubble.

## Details

0.2.2 is a UI polish and DSH 0.2.2 compatibility release: the colored smoke renderer now picks a dominant hue layer per pixel so hues can no longer average into grey; card rows keep the native 8 px right inset and no control paints its own hover block; status icons carry a Session-scoped stable anchor so annotations survive re-renders; the card binds its own wheel listener so DSH 0.2.2's sidebar scroll hand-off no longer swallows the gesture; and all 9 browser locale namespaces were unified into one term per concept with a new copy-fence suite. DSH 0.2.2 changed the native Session hover card's CSS-module classes, so the plugin no longer injects figures there; session statistics appear only on the plugin's own row hover card.
