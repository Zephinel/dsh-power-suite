## Highlights

- 动态工作区与左侧栏：Workspaces 浏览器新增 Active / Inactive Projects 分组和 Running & recent 卡片，实时跟随运行中与近期会话；子代理嵌套展示、未读标绿，悬停可看状态与会话统计、Token、上下文用量；行"…"菜单直接打开 DSH 原生同款菜单；运行/近期两个保留窗口可在插件页调整，工作区右键菜单仍可设置新会话的默认 agent 预设。左侧栏拖动宽度会持久化并在已配对设备间同步，拖动时的彩虹高亮闪烁也已修复。
- 会话产物：右侧栏 Start 页的 Artifacts 卡片汇总当前会话生成的文件和你附在提问里的图片/文件，可筛选、打开、下载、复制或复制局域网链接，并悬停快速预览常见格式。
- 提示历史与草稿附件：修饰键 + ↑/↓ 召回本会话已发送的提示，右侧栏支持悬停全文、搜索与点击复制；草稿附件在切换会话再回来时仍会保留；提示历史修饰键可在插件页调整。
- 中断会话恢复：未正常结束的会话在标题左侧显示琥珀标记和悬停继续按钮，发送键变为播放键；状态由 Host 统一维护、多标签页一致，卡片与原生侧栏行的中断状态也保持一致。
- UI 元素标注：浮动启动器进入点选标注模式，页面让出右侧栏；标注持久化，并可作为原生 composer 引用芯片插入（单条或批量）而不直接发送。
- 更新提醒：有新版本发布后，仍在使用旧版本的页面会在右下角提示，可展开查看本版更新要点、「下次再说」或不再提醒该版本，并可直接打开插件详情页更新。

## Details

0.1.0 是本套件的首个公开发布，把此前从未发布的开发历史一次性打包：会话产物与悬停预览、工作区默认预设、动态工作区、提示历史、草稿附件记忆、中断会话恢复、UI 元素标注、插件设置、Host 同步的侧栏宽度和更新提醒。它安装为单个 bundle `@zephinel/dsh-power-suite`，没有构建步骤，安装后随 DSH Web 一起加载。
