## Highlights

- Dynamic Workspaces and the sidebar: the Workspaces browser gains **Active / Inactive Projects** buckets and a **Running & recent** card that follow running and recently active Sessions live — subagent Sessions nest under their parent, unread completions stay green, and hovering a row shows status plus session statistics, token usage and context usage; the row "…" menu opens the shell's native menu, the two retention windows are adjustable on the plugin page, and the Workspace context menu still sets the default agent preset for new Sessions there. The left sidebar's dragged width is now stored and synced across paired devices, and the rainbow highlight stays steady while the width changes.
- Session artifacts: the right Sidebar's Start page carries an **Artifacts** card listing the current Session's generated files plus the images/files you attached to your prompts, with filtering, open, download, copy content and LAN-link actions, and hover Quick Look for common formats.
- Prompt history and draft attachments: the configured modifier + ↑/↓ recalls prompts already sent in this Session; a right-edge rail adds full-text hover previews, inline search and click-to-copy, and the modifier is configurable on the plugin page. Attachments in a draft survive switching Sessions and coming back.
- Interrupted-session recovery: unfinished Sessions carry an amber mark left of the title, a hover-revealed Continue button, and a play-shaped composer submit control. The state is Host-owned and consistent across tabs, and the card and native sidebar rows agree on it.
- UI element annotation: a floating launcher toggles a point-and-click annotation mode that makes room for a right rail; annotations persist, and references are inserted as native composer inline reference chips (single or one grouped batch) without sending.
- Update notice: after a newer version is published, pages still running an older one show a bottom-right notice with that release's highlights, a way to postpone it, a "don't remind me for this version" option, and a shortcut to the plugin details page to update.

## Details

0.1.0 is the first public release of this suite and bundles all previously unpublished development history: session artifacts with hover Quick Look, per-Workspace default agent presets, Dynamic Workspaces, prompt history, draft attachment memory, interrupted-session recovery, UI element annotation, plugin settings, a Host-synced sidebar width, and the in-app update notice. It installs as the single bundle `@zephinel/dsh-power-suite`, needs no build step, and loads with DSH Web once installed.
