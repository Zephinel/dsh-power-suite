## Highlights

- Session artifacts card: the right Sidebar's Start page now carries an **Artifacts** card listing the current Session's generated files plus the images/files you attached to your prompts, with filtering, open, download, copy content and LAN-link actions, and hover Quick Look for common formats.
- Dynamic Workspaces: the Workspaces browser gains **Active / Inactive Projects** buckets and a **Running & recent** card that follow running and recently active Sessions live; subagent Sessions nest under their parent, unread completions stay green, and hovering a row shows its status plus session statistics, token usage and context usage. A Workspace context-menu submenu sets the default agent preset for new Sessions there, and the two retention windows are adjustable on the plugin page.
- Prompt history and draft attachments: the configured modifier + ↑/↓ recalls prompts already sent in this Session; a right-edge rail adds full-text hover previews, inline search and click-to-copy, and the modifier is configurable on the plugin page. Attachments in a draft survive switching Sessions and coming back.
- Interrupted-session recovery: unfinished Sessions carry an amber mark left of the title, a hover-revealed Continue button, and a play-shaped composer submit control. The state is Host-owned and consistent across tabs.
- UI element annotation: a floating launcher toggles a point-and-click annotation mode that makes room for a right rail; annotations persist, and references are inserted as native composer inline reference chips (single or one grouped batch) without sending.
- Update notice: after a newer version is published, pages still running an older one show a bottom-right notice with that release's highlights, a way to postpone it, a "don't remind me for this version" option, and a shortcut to the plugin details page to update.

## Details

0.1.0 is the first public release of this suite and bundles all previously unpublished development history: session artifacts with hover Quick Look, per-Workspace default agent presets, Dynamic Workspaces, prompt history, draft attachment memory, interrupted-session recovery, UI element annotation, plugin settings, and the in-app update notice. It installs as the single bundle `@zephinel/dsh-power-suite`, needs no build step, and loads with DSH Web once installed.
