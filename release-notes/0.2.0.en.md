## Highlights

- The sidebar rainbow atmosphere and annotation surfaces now follow the light/dark theme consistently: dark mode is softer, each hue keeps a consistent perceived lightness and saturation per theme, and the smoke drifts and diffuses slowly instead of flickering.
- Two real annotation-mode bugs are fixed: clicking page elements no longer throws, and copying an XPath / JS path shows the correct feedback instead of an error toast.
- The browser-side plugin code is now fully typed, and the release checks execute the real shipped bundle; loading and upgrading are more reliable and future changes are less likely to regress.
- The update notice now reports the version that is actually running, making it easier to decide whether to upgrade.

## Details

0.2.0 is the first release after the TypeScript migration. Plugin behavior, UI and installation are unchanged; the work focuses on browser-side reliability, light/dark theme consistency, annotation-mode fixes and pre-release checks.
