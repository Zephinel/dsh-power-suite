## Highlights

- 左侧栏的彩虹氛围与注释浮层现在统一跟随浅色/深色主题：深色更柔和、颜色在各自模式下保持一致的亮度与饱和度，烟雾会缓慢流动、扩散，不再闪烁。
- 修复注释模式里的两个真实问题：点击页面元素不再报错；复制 XPath / JS 路径时会显示正确的提示，不再出现错误 toast。
- 浏览器端的插件代码已完整类型化，并加入对真实发布产物的执行检查；插件加载与升级更稳，后续功能改动更不容易引入回归。
- 更新提示现在会准确显示正在运行的插件版本，方便判断是否需要升级。

## Details

0.2.0 是 TypeScript 迁移完成后的首个版本。插件的行为、界面与安装方式保持不变；主要变化集中在浏览器端可靠性、浅色/深色主题一致性、注释模式修复和发布前检查。
